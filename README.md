# 💻 For Web Application

### 🔹 Basic Usage

1. Open the website.  
2. Enter a job title (e.g., *Full Stack Developer Intern*).  
3. Upload a resume in PDF format.  
4. Click **Analyze Resume**.  
5. View:  
   - ATS Score  
   - Matched Skills  
   - Missing Skills  
   - Improvement Suggestions

## 📊 ATS Score Logic

```
ATS Score = (Matched Skills / Total Required Skills) × 100
```

### Additional Evaluation Factors:
- Core technical skills  
- Soft skills presence  
- Education relevance  
- Job-role matching percentage
